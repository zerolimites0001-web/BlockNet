# BlockNet ⛏️

Jogo de blocos no navegador — quebra, constrói e explora mundos gerados na hora. Com suporte a mods (ex: Steve) e editor de HUD.

## Rodar

Abra `index.html` no navegador, ou sirva a pasta:

```sh
python3 -m http.server
```

## Mods

Jogue arquivos `.zip` em `mods/` e liste em `mods/manifest.json`.
